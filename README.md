# Simulador de Planificación de Procesos - SRTF

Este proyecto es un simulador del algoritmo de planificación de CPU **Shortest Remaining Time First (SRTF)**, desarrollado para la asignatura de Sistemas Operativos.

## 🚀 Características
- Interfaz gráfica intuitiva con **Tkinter**.
- Cálculo automático de:
  - Tiempo de Finalización ($T_f$).
  - Tiempo de Vuelta ($T_v$).
  - Tiempo de Espera ($T_e$).
- Generación de **Diagrama de Gantt** dinámico con marcas de tiempo y duraciones.
- Soporte para cualquier número de procesos.

## 🛠️ Requisitos
- Python 3.x
- Matplotlib (`pip install matplotlib`)

## 📋 Ejemplo de Uso
Para probar el ejercicio clásico:
1. P0: Llegada 0, NCPU 900
